Hermes Personal Agent

A single-user, self-hosted assistant. Not a public product.

Privacy Policy Terms of Service

What this application is

Hermes Personal Agent is a private automation tool operated by and for a single individual, its owner. It is not distributed, not published to any app store, and has no other users. There is no sign-up, no user base, and no service offered to the public.

What it does with Google data

With the owner's explicit consent, the application connects to the owner's own Google account to:

  • search and read the owner's Gmail messages, so the owner can ask questions about his own inbox;
  • read and manage the owner's Google Calendar events, so the owner can view, create or move his own appointments.

All Google user data stays on infrastructure controlled by the owner. It is never sold, never shared with third parties, and never used for advertising, profiling or training machine-learning models. The full details are in the Privacy Policy.

Scope of use

The application requests only two families of permissions: Gmail and Calendar. It does not request Drive, Contacts, Sheets, Docs or any other Google service. Permissions can be revoked by the owner at any time from his Google Account security settings.
